# Teach & Repeat Rover Navigation

Initial 2-D simulation for recovering a human-demonstrated rover route from displaced starting poses. The project compares direct waypoint tracking, grid A* local reconnection, a classical discrete DMP, and a DMP with obstacle coupling. A separate synthetic point-cloud example demonstrates ICP localization.

## Project update

The [October 7 presentation](docs/Teach_and_Repeat_Project_Update_Oct_7_2026.pptx) and [PDF preview](docs/Teach_and_Repeat_Project_Update_Oct_7_2026.pdf) contain screenshots generated by the simulation and the [originally proposed metrics](docs/project_scope.md). The underlying data are in [`results/trials.csv`](results/trials.csv) and [`results/metrics.json`](results/metrics.json).

| Method | Completed | Path rejected | Safety stopped | Collided |
| --- | ---: | ---: | ---: | ---: |
| Direct waypoints | 70.0% | 30.0% | 0.0% | 0.0% |
| Local reconnection | 76.7% | 10.0% | 13.3% | 0.0% |
| Classical DMP | 35.0% | 65.0% | 0.0% | 0.0% |
| Obstacle-aware DMP | 53.3% | 45.0% | 1.7% | 0.0% |

These are **preliminary simulation results**, not physical-rover performance. Each method uses the same 60 start poses and feedback controller. Unsafe candidate paths are rejected; the rover stops if its executed path crosses the 0.12 m safety margin. The ICP example is separate from these navigation trials, which currently use exact pose. Planning times vary by computer and run.

## Reproduce

```powershell
python -m pip install -r requirements.txt
python src/robot_motion.py
python build_slides.py
```

The simulation command generates CSV, JSON, and plot images in `results/`. The slide command creates a PowerPoint deck in `docs/` with the cream-and-teal style of the team's original presentation.
